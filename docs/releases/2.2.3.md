# v2.2.3

Suíte de testes de verdade, do backend ao frontend: os testes do frontend
saíram do `bun test` (que não executava a suíte) para o **vitest com
cobertura**, novos testes Go cobrem pacotes que estavam descobertos e o e2e
ganhou a matriz de abas. De brinde, o `wails3 dev` voltou a ser rápido —
ele não roda mais a suíte inteira a cada rebuild do watcher.

## Destaques

- **Frontend testado de ponta a ponta**: a suíte (stores, parsers e
  helpers) agora roda no **vitest** — 163 testes verdes e cobertura v8
  (75,8% dos statements dos módulos medidos). O runner próprio do Bun não
  implementa os recursos que a suíte usa (`vi.hoisted`, ambiente jsdom e o
  setup do testing-library) e falhava em 2 arquivos.
- **Testes Go novos**: `models` (paths de evento/versão), `datastore`
  (registry), `core/strings` (keyed strings), `objectsfile` (layouts) e
  `services` (filtros de metadata) — pacotes que estavam sem cobertura
  nenhima; a suíte de `eventtable` foi expandida.
- **E2E: matriz de abas**: novo spec cruza as versões do jogo (FFX, FFX-2,
  Eternal Calm, Last Mission) com as abas, com helpers novos de troca de
  aba, coluna e progresso.
- **`wails3 dev` ágil**: o modo de desenvolvimento builda sem o portão de
  testes (task `build:dev`) — iterar na UI não espera mais a suíte inteira
  rodar a cada save.
- **Portão intacto na release**: `wails3 build`, `task build` e
  `task release` continuam rodando **todos** os testes antes de compilar e
  abortam no primeiro vermelho — binário vermelho não sai.

## Como usar

- Rodar a suíte quando quiser: `wails3 task test` (Go + frontend).
- Desenvolvimento normal: `wails3 dev` compila direto, sem testes no meio
  do caminho.
- Nada muda no uso do editor: esta versão é de infraestrutura de testes e
  do fluxo de build.

## Escopo

- `test(frontend)`: migração da suíte para o vitest — configuração
  (`vitest.config.mjs`, `vitest.setup.ts`), scripts `test`/`test:watch`/
  `test:ui` no `package.json` e ajuste dos imports de bindings para o
  runner resolver.
- `test(backend)`: testes novos em `models`, `datastore`, `core/strings`,
  `objectsfile/file_layouts` e `services/metadata_filters`; expansão dos
  testes de `eventtable`.
- `test(e2e)`: spec `tabs-matrix` e helpers de aba/coluna/progresso.
- `build(task)`: task `build:dev` (build sem `version:sync` e sem a task
  `test`) usada pelo `dev_mode.executes` do `build/config.yml`;
  `test:frontend` passa de `bun test` para `bun run test` (vitest).
- `docs(release)`: nota da 2.2.2 removida — a versão já está publicada e a
  nota estava desatualizada.
