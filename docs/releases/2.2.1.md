# v2.2.1

Correção de tema: a janela de atualização agora segue o tema do app.

## Destaques

- **Tema sincronizado**: a janela de atualização abre no mesmo tema
  (claro/escuro) do app. Antes ela seguia o tema do sistema operacional e
  ficava clara mesmo com o app no escuro.
- **Sync ao vivo**: alternar o tema no app (☾/☀) com a janela de atualização
  já aberta troca o tema da janela na hora, sem recarregar.
- **Fonte única de tema**: `dark|light` passa a viver no backend, persistido
  no `config.json` (campo `Theme`), e é compartilhado pelo frontend e por
  qualquer janela filha de HTML embutido.

## Como usar

- Nada a configurar: a janela usa o mesmo tema que já está escolhido no
  botão ☾/☀ do app.
- Na primeira troca de tema o `config.json` ganha `"Theme": "dark"` (ou
  `"light"`).

## Escopo

- `feat(updater)`: tema na janela de atualização — `data-theme` renderizado
  no HTML na abertura (`__FFX_THEME__`) e evento `ffx:theme` para a janela
  já aberta (troca só do atributo; o CSS é dirigido por ele).
- `feat(config)`: campo `Theme` no config, com `GetTheme`/`SetTheme` no
  ConfigService para o frontend espelhar o `next-themes`.
